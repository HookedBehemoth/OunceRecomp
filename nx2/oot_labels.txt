# Labels for the lifted game's functions (nx2/label_syms.py): <guest address> <label> [# where it is documented: what]
# Descriptions of ours, not the game's names. Lower case, digits, underscores; every address and label once.
# An entry is a function's entry address in this lift (HOS_GAME_VERSION 100). Add what an analysis finds, with its note
# (docs/development.md, Function labels). A label says what the note says, no more: a role ("_reader_b", "_caller")
# when that is all it knows; '# ?' marks a doubt or notes that disagree. Mid-function sites (lr, splice points) name the
# function that contains them.
