# gpu/legacy

Upstream Hookshot's renderers, kept as reference source: the Vulkan back end (`vk/`), the WebGPU renderer (`render/`) and
the suyu code they build on (`third_party/`), with the tools and scripts that served them (`tools/`, `scripts/`). Nothing
here is built, tested or run; the direct back end in `gpu/direct` is the renderer.
